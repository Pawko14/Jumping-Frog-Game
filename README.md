# Jumping Frog Game 

This project is a game where the player needs to go to the end of the road without getting in contact with enemy cars or with a stork
Friendly cars helps the player 

# Execution 
Repository is ready to run. It is only needed to open Visual Studio 

# Requirements
Visual Studio 2022
Edition	Windows 10 Education N
